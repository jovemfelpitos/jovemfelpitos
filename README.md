### Olá, sou o Luis Felipe.

Analista de Sistemas com experiência em desenvolvimento, sustentação e evolução de sistemas corporativos. Trabalho com **integrações via APIs, automação de processos, SQL e qualidade de dados**, conectando necessidades de negócio à implementação técnica.

Meu foco está nos sistemas que sustentam a operação: CRMs, ferramentas internas, fluxos de dados e aplicações que ajudam as equipes a trabalhar com mais organização e rastreabilidade.

### O que faço

- **Sistemas:** levantamento de necessidades, desenvolvimento, testes, homologação e sustentação.
- **Integrações:** APIs REST, comunicação entre plataformas e investigação de falhas.
- **Dados:** consultas SQL, higienização, validação, importação e automação de rotinas.
- **Operação:** controle de acesso, auditoria e evolução de ferramentas utilizadas no dia a dia.

### Tecnologias

**Desenvolvimento:** Python · PHP · JavaScript · SQL  
**Backend e integrações:** Flask · FastAPI · Django · SQLAlchemy · APIs REST  
**Dados:** MySQL · PostgreSQL · SQLite · Pandas · Polars · Parquet  
**Interfaces e ambiente:** React · Next.js · TypeScript · Git · Linux · Docker
